# بکاپ و Restore (TASK-070)

> **وضعیت: اسکریپت‌ها نوشته شده‌اند، اجرا نشده‌اند.** PostgreSQL در محیط ساخت نبود؛ معیار «بازیابی در محیط آزمایشی موفق باشد» هنوز **تأیید نشده**. بعد از اولین اجرای واقعی، نتیجه را در پایین همین فایل ثبت کنید.

## چه چیزی بکاپ می‌شود
1. پایگاه داده: `pg_dump --format=custom` (شامل جدول `__EFMigrationsHistory`).
2. فایل‌های پیوست (`Storage:Root`) به‌صورت `files.tar.gz`.
3. فهرست `attachments.tsv` (شناسه، SHA-256، کلید ذخیره) از خود پایگاه داده در همان لحظه، برای اثبات سازگاری فایل و رکورد.
4. `SHA256SUMS` از هر سه فایل. اگر `BACKUP_RECIPIENT` (age) تنظیم باشد کل پوشه رمز می‌شود؛ بدون آن هشدار داده می‌شود (بکاپ حاوی داده‌های سازمانی است و باید رمز شود).

اجرا (روزانه با cron/Scheduler؛ رمز پایگاه داده از Secret store، نه خط فرمان):
```bash
PGHOST=db PGUSER=ksc PGDATABASE=ksc_meeting STORAGE_ROOT=/var/lib/ksc/files \
BACKUP_RECIPIENT=age1... KEEP=14 deploy/backup/backup.sh /backups
```
نگه‌داری: ۱۴ بکاپ آخر (`KEEP`)؛ یک نسخه را خارج از سرور (آفسایت) نگه دارید.
محدودیت: فایل و رکورد در دو لحظهٔ نزدیک گرفته می‌شوند؛ پیوستی که بین آن‌ها آپلود شود ممکن است در فایل‌ها باشد ولی در فهرست نه (بی‌خطر) یا برعکس (در اعتبارسنجی «missing» می‌شود). برای بکاپ سازگار کامل برنامه را موقتاً Read-only کنید یا از Snapshot دیسک استفاده کنید.
WAL/Point-in-time در این گام نیست (RPO = فاصلهٔ بکاپ‌ها).

## بازیابی و اعتبارسنجی (محیط آزمایشی)
```bash
age -d -i key.txt /backups/ksc-<stamp>.tar.age | tar -x -C /tmp/restore
deploy/backup/verify-restore.sh /tmp/restore/ksc-<stamp> ksc_restore_test
```
اسکریپت: SHA256SUMS را بررسی می‌کند؛ پایگاه آزمایشی **خالی** می‌سازد (روی پایگاه غیرخالی یا برابر `PGDATABASE` نمی‌ایستد)؛ `pg_restore` می‌کند؛ بررسی می‌کند Migrationها هستند، رکوردهای یتیم نیست (شرکت‌کننده/پیوست بدون جلسه، نسخهٔ صورت‌جلسه بدون صورت‌جلسه)، شمارهٔ جلسه تکراری نیست، و هر فایل پیوست وجود دارد و SHA-256 آن با پایگاه داده برابر است؛ سپس پایگاه آزمایشی را حذف می‌کند. خروجی غیر از صفر یعنی بازیابی معتبر نیست.

بازیابی واقعی (فاجعه): برنامه را متوقف کنید → پایگاه داده جدید بسازید → `pg_restore` → `files.tar.gz` را در `Storage:Root` باز کنید → اجرای `verify-restore` روی همین بکاپ پیش از شروع برنامه → `/health/ready` سبز → برنامه را روشن کنید.
