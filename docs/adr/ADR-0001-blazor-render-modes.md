# ADR-0001 — Blazor Render Modes و مرز UI اتاق جلسه (TASK-001)

**وضعیت:** Accepted  
**تاریخ:** 2026-10-20

## تصمیم
- پوسته اصلی: **Blazor Web App** روی .NET 10 (LTS).
- صفحات مدیریتی (جلسات، کمیته، گزارش، تنظیمات): **Interactive Server** در شروع؛ پس از آزمون ظرفیت اتصال SignalR قابل ارتقا به Auto است.
- Scheduler و Date Picker شمسی: کتابخانه مستقل `KSC.MeetingManagement.Calendar`، مستقل از Render Mode (فقط وابسته به `IMeetingCalendarDataProvider`).
- **اتاق جلسه آنلاین:** صفحه جداگانه با مرز کلاینتی مستقل؛ SDK رسانه (LiveKit JS) از طریق JS Interop بارگذاری می‌شود. اتصال رسانه (WebRTC) کاملاً مستقل از اتصال SignalR برنامه است؛ قطع SignalR نباید جلسه را قطع کند و بالعکس.
- صفحات مهمان/پیش‌نمایش: بدون وابستگی به نشست Identity سازمانی، با توکن دعوت.

## محدودیت‌ها و مقیاس‌پذیری
- هر مدار Interactive Server حافظه سرور مصرف می‌کند؛ ظرفیت کاربران هم‌زمان باید در تست بار اندازه‌گیری شود.
- حالت وضعیت اتاق (mute، شرکت‌کنندگان) در کلاینت/LiveKit نگه‌داری می‌شود، نه در مدار Blazor.
- API تجاری (REST) مستقل از UI است تا امکان تغییر Render Mode یا کلاینت دیگر وجود داشته باشد.
