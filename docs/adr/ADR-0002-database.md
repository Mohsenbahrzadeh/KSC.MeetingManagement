# ADR-0002 — انتخاب دیتابیس (TASK-002)

**وضعیت:** Accepted (تأیید مالک محصول، 2026-10-20)  
**تاریخ:** 2026-10-20

## گزینه‌ها
| معیار | PostgreSQL | SQL Server |
|---|---|---|
| مجوز/هزینه | متن‌باز، بدون هزینه | نیازمند مجوز (یا Express محدود) |
| EF Core | Npgsql، بالغ | رسمی، بالغ |
| استقرار با Docker Compose | ساده | سنگین‌تر |
| ابزار پشتیبان‌گیری | pg_dump، WAL | ابزارهای بومی |
| تجربه تیم/سازمان | نامشخص | نامشخص |

## پیشنهاد
**PostgreSQL** (عدم هزینه مجوز، تناسب با استقرار خودمیزبان Docker Compose). EF Core طوری لایه‌بندی می‌شود که تعویض provider پرهزینه نباشد (بدون SQL خام وابسته به provider در Application).

## پذیرش
با تأیید، یک نمونه در محیط توسعه اجرا و migration اولیه آزموده می‌شود.
