# ADR-0005 — SLO اولیه و مرورگرهای هدف (TASK-005)

**وضعیت:** Proposed — مقادیر عددی پس از اندازه‌گیری PoC نهایی می‌شوند  
**تاریخ:** 2026-10-20

## مرورگرهای هدف (پیشنهاد)
- دسکتاپ: آخرین دو نسخه Chrome، Edge، Firefox؛ Safari 17+
- موبایل: Chrome Android (آخرین ۲ نسخه)، Safari iOS 17+

## اهداف اولیه (قابل بازنگری)
- هر اتاق: ۱۰ تا ۲۵ شرکت‌کننده
- p95 فهرست جلسات بازه‌ای: هدف اولیه < 500ms (باید اندازه‌گیری شود)
- ظرفیت هم‌زمان کل و دسترس‌پذیری/RPO/RTO: **تعیین نشده**؛ نیازمند ورودی کسب‌وکار
