# KSC.MeetingManagement

## اجرای محلی

برای پیش‌نیازها و دستورهای کامل اجرای API و وب، PostgreSQL، migrationها و حساب development به [راهنمای اجرا](docs/DEVELOPMENT.md) مراجعه کنید. خلاصه: .NET SDK نسخهٔ `10.0.402` و PostgreSQL لازم است؛ اجرای کامل تماس صوتی/تصویری به LiveKit/coturn و مرورگر با HTTPS هم نیاز دارد.
